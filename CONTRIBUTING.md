# Contributing

Thank you for helping improve this project.

## How to contribute

1. Fork the repository.
2. Create a feature or bugfix branch.
3. Make your changes and keep them focused.
4. Test your changes before submitting.
5. Open a pull request with a clear description.

## Guidelines

- Keep code clean and readable.
- Follow the existing project style.
- Update documentation when behavior changes.
- Avoid adding unnecessary dependencies.
- If you change the database schema, update Database_Schema.sql.

## Development tips

- Use the provided setup scripts to prepare your environment.
- Run the app locally before submitting changes.
- If you add new features, document them in the README.

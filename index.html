getting started

Set it up in under five minutes

Prerequisites: Python installed and on PATH, a running MySQL server (XAMPP works well locally), and pip.

Windows
macOS / Linux

Install Python and MySQL

Grab Python from python.org (enable "Add to PATH"), then install XAMPP and start Apache + MySQL from its control panel.

Create the database

Import Database_Schema.sql through phpMyAdmin, or run the schema SQL manually — see the schema section below.

Set environment variables

Run enviroment.bat, or set DB_HOST, DB_USER, DB_PASSWORD, and DB_NAME yourself.

Run the setup script

Double-click setup.bat — it installs dependencies, imports the schema if needed, and launches the app.

database

The employees table

One table, six columns. Import Database_Schema.sql in phpMyAdmin, or run this directly in MySQL.

Database_Schema.sql
CREATE DATABASE IF NOT EXISTS Employees
CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;

USE Employees;

CREATE TABLE IF NOT EXISTS employees (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    position VARCHAR(100) NOT NULL,
    salary DECIMAL(10, 2) NOT NULL CHECK (salary >= 0),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB;
id PKINT, auto-increment
nameVARCHAR(100)
positionVARCHAR(100)
salaryDECIMAL(10,2), ≥ 0
created_atTIMESTAMP
updated_atTIMESTAMP, auto
packaging

Build a standalone .exe

A PyInstaller spec file ships with the project, so most people won't need the manual command.

using the spec file
pyinstaller --clean EmployeeManagementSystem.spec
manual build
pyinstaller --onefile --windowed \
  --icon app.ico \
  --add-data "app.png;." \
  --add-data "app.ico;." \
  --name EmployeeManagementSystem main.py

On macOS/Linux, replace the semicolons in --add-data with colons. Output lands in dist/.

troubleshooting

When something doesn't start

ModuleNotFoundError: mysql.connector+
The connector isn't installed in your active environment. Run pip install mysql-connector-python and try again.
Database connection failed+
Check that MySQL is running, that DB_HOST, DB_USER, and DB_PASSWORD are correct, and that the database in DB_NAME actually exists.
App can't find the database+
Confirm the name in DB_NAME matches the database you created — it defaults to Employees.
pyinstaller: command not found+
PyInstaller isn't installed yet. Run pip install pyinstaller, then re-run your build command.
